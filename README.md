# 谭成义·麦当劳减脂餐

一个垂直的 Codex Skill：按谭成义的体重×运动量框架计算每日三大营养素，再把早餐、午餐、晚餐结构映射到麦当劳中国门店的当前菜单。用户确认餐单后，可以计算价格并创建到店自取订单。

它不是通用点餐助手，也不是麦当劳官方产品。默认只处理到店自取；外送、团餐、优惠券、商城和抽奖不进入主流程。餐品热量、营养和供应情况以 MCP 返回为准。

## 目标用户

- 正在按谭成义的“体重×运动量”方法安排饮食的 18 岁以上用户。
- 想知道当天麦当劳菜单里哪些组合最接近燕麦、米饭、薯类、瘦蛋白和蔬菜结构的人。
- 已经吃过一部分食物，只想安排剩下餐次的人。
- 餐单确定后希望直接看价格并到店自取下单的人。

本项目不面向需要医疗营养治疗的人群，也不以极端节食、快速减重或单一食物替代正餐为目标。

## 安装

1. 将 `skills/tan-mcd-meal-coach` 复制到 `~/.codex/skills/tan-mcd-meal-coach`。
2. 在麦当劳 MCP 平台申请个人 Token，并通过系统安全的环境变量管理方式提供 `MCD_MCP_TOKEN`。不要把真实 Token 写进仓库或对话。
3. 配置 Codex：

   ```sh
   codex mcp add mcd-mcp --url https://mcp.mcd.cn --bearer-token-env-var MCD_MCP_TOKEN
   ```

4. 重启或新开 Codex 会话后，调用 `$tan-mcd-meal-coach`。

脱敏配置见 [`mcp-config.example.json`](mcp-config.example.json)。本项目只包含变量占位符。

## 信息采集

信息不足时优先展示 [信息采集表单](skills/tan-mcd-meal-coach/assets/intake-form.html)。表单使用输入框和选择框收集体重、性别、运动时长、餐次、城市/地标、取餐方式和可选已吃食物；点击“开始安排”后会直接发送请求到当前对话，不需要复制粘贴。当前客户端不支持内联表单时，再退回简短文字提问。

性别只用于选择参考表系数，不从姓名、外貌或历史记录推断。MCP 不提供体重和性别的通用用户资料接口；已保存的配送地址属于敏感信息，只有用户明确要求时才读取，不会自动填入到店自取表单。

表单一次点击只发送一次；发送成功后锁定 30 秒，遇到 `429` 会停止重试并提示等待，避免重复请求放大限流。

## 使用示例

- “我 72kg，女，每周运动 4–5 小时，上海人民广场，帮我配今天三餐。”
- “同一组数据，只安排晚餐，上海人民广场。”
- “我早餐吃了 2 个鸡蛋和一杯拿铁，午餐吃了 150 克米饭和一份鸡胸肉，晚餐想吃麦当劳。”
- “晚餐换成麦当劳，按这家店的实时菜单和营养数据搭配。”
- “晚餐这套可以，报价后帮我下单。”

Skill 会先利用用户已经说过的信息；缺少关键项时，优先用表单收集，表单不能展示时再用一条消息问完。查找门店时只使用用户主动提供的城市和商圈/地标，不读取或推断精确定位。

## 返回格式

安排完成后固定返回四块内容：

1. 今日目标：当前体重、档位、运动时长和目标营养素。
2. 菜单与营养表：餐次、餐品、份量、能量、碳水、蛋白质、脂肪、钠和来源。
3. 合计与差额：本单、当日累计和相对目标差额。
4. 下一步：报价、下单或继续调整。

营养表按餐列出商品，并带餐次小计；全天方案再加全天合计。缺失数据写 `—`，估算用区间，不把不同来源的数据混成精确值。

用户只指定一餐时，只输出该餐菜单和本餐营养表。用户说“下单”但没有指定餐次时，先问要下早餐、午餐还是晚餐；一次订单只包含选定的一餐。

## 业务价值

把“算目标、查门店、看菜单、核对营养、安排剩余餐次、确认下单”串成一条短路径。用户不需要在通用工具和饮食方法之间来回切换，也不会被优惠券、商城或外送流程打断。

## 方法

初始宏量营养素估算参考谭成义的《三个月生活化减脂全攻略：吃多少、吃什么、怎么调》。公式只作为透明、可修改的起始估算，不代表经过个体评估的每日能量消耗或减脂缺口。每 7–10 天复盘一次，调整时优先小幅增减碳水，蛋白质尽量保持不变。

麦当劳餐品优先使用 MCP 数据；家常食物和资料示例按来源标注估值。菜单中的食物只近似对应参考结构，不会被描述成完全等同燕麦、糙米或家常菜。

## 安全范围

- 不保证减重结果，也不把短期体重波动当作需要立刻调餐的依据。
- 不为未成年人、孕期或哺乳期用户，以及有慢性病、相关用药或饮食障碍经历的用户生成个性化减脂目标；建议咨询医生或注册营养专业人员。
- 餐单阶段只报价，不建单。用户明确确认后才创建到店自取订单；不自动支付，也不声称已经支付成功。
- 不处理外送、团餐、领券、商城、抽奖、取消订单或查询他人订单；用户改成到店自取时再继续。
- MCP Token、个人资料和用餐记录不写入项目文件。
